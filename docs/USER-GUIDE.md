> 面向：你（管理员）。目的：从空数据库开始，5 分钟跑出一条完整业务链，看懂每个页面能做什么。
> 依据：`main` 分支 `ccbcf6e`。界面入口与表单字段均已与代码核对。

## 二、5 分钟跑通一条完整业务链

按这个顺序走，每步都能看到数据增加。

### 第 1 步：建一个客户（30 秒）

1. 左侧点 **客户** → 右上角 **+ 新建客户**
2. 填写：
   - **客户名称**（必填）：如 `示例科技`
   - **客户等级**：高/中/低价值
   - **负责人**：选你自己（`nickxiao`）
   - 行业、电话、邮箱、地址、备注（选填）
3. 点保存

> ✅ 因为选了负责人，**你的飞书会收到一张「新客户分配」卡片**（需 `npm run feishu:events` 或至少消息发送权限正常）。

### 第 2 步：进客户详情，补联系人和跟进（1 分钟）

点刚建的客户名称进详情页，这里有 4 个区块：

- **基本信息** → 下方有**编辑表单**，可改等级/行业/电话/邮箱/地址/备注
  - 另外能看到并（以管理员身份）修改 **客户生命周期**：线索 / 成交 / 留存 / 流失
    > 注意：这是**人工维护**的标签，不会因为线索转化或商机赢单而自动变化
- **联系人** → 可**新增 / 编辑 / 删除**（姓名、职位、电话、邮箱、备注）
- **商机** → 显示该客户下所有商机
- **跟进记录** → 有**新增跟进**表单：方式（电话/面谈/邮件/即时消息/其他）、内容、下次跟进时间

试试：加一个联系人（如"张三 / 技术总监"），再写一条跟进记录内容"初次电话沟通，介绍产品"。

### 第 3 步：建一条线索，然后转化（1 分钟）

1. 左侧 **线索** → **+ 新建线索**
   - 线索名称、负责人、状态（**新线索 / 跟进中 / 已转化 / 无效**）、来源（如"官网表单"）、电话、邮箱
2. 保存后，在列表里点 **转化为商机**
3. 系统会**自动**：新建一个同名客户、新建一个商机、把线索标记为「已转化」

> 这就是"线索 → 客户 + 商机"的转化，事务性完成，不会留下半截数据。

### 第 4 步：给商机做报价 → 合同 → 订单 → 回款（2 分钟）

这是完整的"收钱"链路：

1. **商机** → 点商机名称进详情
2. 详情页里找 **报价** 区块 → **新建报价** → 添加多个条目（名称、数量、单价），金额自动汇总
3. 报价行上点 **转为合同** → 生成合同，来源可追溯
4. 左侧 **合同** → 点合同进详情 → **转为订单**
5. 左侧 **订单** → 点订单进详情 → 底部 **登记回款**（金额、到账时间）
   - 页面会显示：**订单金额 / 已回款合计 / 未收差额**

### 第 5 步：看汇总（30 秒）

1. 左侧 **销售漏斗** → 六个阶段（初步接触 / 需求确认 / 报价 / 谈判 / 赢单 / 输单）各有多少商机，点任一阶段下钻到该阶段的商机列表
2. 左侧 **概览** → 四个数字卡片应都有数据了

## 三、公海与认领（负责人之间的客户流转）

1. 管理员在客户详情里把某客户**负责人清空** → 这个客户进入 **公海**
2. 任何负责人在 **公海** 页可以看到它（只看名称/等级/行业，看不到联系方式——安全设计）
3. 点 **认领** → 自己成为负责人，收到飞书通知
4. 两个人同时认领 → 只有一个成功（原子更新，先到先得）

## 四、权限规则（当前只有你一个人，但规则已生效）

| 角色                 | 能看到什么                                                        |
| -------------------- | ----------------------------------------------------------------- |
| **管理员**（你现在） | 全部客户/线索/商机/合同/订单/回款，可移交负责人，可改客户生命周期 |
| **普通负责人**       | 只有自己负责的对象；越权访问统一返回"未找到"（不泄露是否存在）    |

想让别人也能用：

1. **设置 → 用户与角色** → 把某人设为管理员（或命令行 `npm run admin -- grant --open-id ou_xxx`）
2. 对方登录后就是普通负责人；需要更全权限再提升

## 五、飞书通知在哪触发

| 操作                 | 飞书收到什么         |
| -------------------- | -------------------- |
| 新建客户并指定负责人 | 「新客户分配」卡片   |
| 新建商机并指定负责人 | 「商机创建提醒」卡片 |
| 认领公海客户         | 「客户认领」卡片     |

> 通知失败**不会**影响业务保存（静默容错），所以没收到卡片时先查 `FEISHU_APP_SECRET` 和机器人能力。

## 六、当前没有的功能（别找了）

这些 GLOSSARY 里有、但界面还没做的：

- ❌ **分页**与**按负责人/状态等高级筛选**（客户列表有搜索框，可按名称/电话/邮箱搜；线索和商机列表没有搜索）
- ❌ 跟进记录的**提醒**（有"下次跟进时间"字段，但没有定时推送）
- ❌ 报价的**导出/打印**
- ❌ 数据**批量导入**（Excel/CSV）
- ❌ 用户**删除**（只能改角色）

需要哪个再单独提。

## 七、怎么重置数据重来

想清空重跑一遍：

```bash
cd /Users/nickxiao/Documents/fscrm

# 只清业务数据，保留用户
psql "postgresql://fscrm:fscrm_dev@localhost:5432/fscrm" -c "
TRUNCATE payments, orders, contracts, quotation_items, quotations,
         follow_ups, opportunities, contacts, customers, leads RESTART IDENTITY CASCADE;"
```

## 八、常用命令速查

```bash
cd /Users/nickxiao/Documents/fscrm
export npm_config_cache="$PWD/.npm-cache"

npm run dev                 # 启动网站（http://localhost:3000）
npm run feishu:events       # 启动飞书事件长连接（另开一个终端，常驻）
npm run feishu:sync-contacts # 同步飞书通讯录到 CRM
npm run admin -- grant --open-id ou_xxx   # 任命管理员
npm run admin -- revoke --open-id ou_xxx  # 撤销管理员
```

> 跑 `prisma`/`db:*` 命令前记得先：`set -a; . ./.env.local; set +a`
