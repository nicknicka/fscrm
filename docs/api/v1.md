# 只读业务数据 API v1

`GET /api/v1/{resource}` 供外部系统读取 CRM 业务数据。接口只读、无写入端点；权限口径与网页端完全同源，不设第二套权限模型。

## 端点与资源白名单

| 端点                        | 说明 |
| --------------------------- | ---- |
| `GET /api/v1/customers`     | 客户 |
| `GET /api/v1/leads`         | 线索 |
| `GET /api/v1/opportunities` | 商机 |
| `GET /api/v1/contracts`     | 合同 |
| `GET /api/v1/orders`        | 订单 |

仅支持上表中的资源名；其它资源返回 `404 {"error":"UNKNOWN_RESOURCE"}`。仅支持 `GET` 方法，不提供创建、更新或删除。

## 鉴权

二选一，优先级如下：

1. **API Key（优先）**：请求头 `Authorization: Bearer <api_key>`。解析出的用户身份决定数据权限范围；即使请求同时带了网页登录 Cookie，也不会用会话身份覆盖 API Key 关联的用户。无效 Key 或其关联用户不存在时直接返回 `401`，不回落到 Cookie。
2. **Cookie 会话（其次）**：没有 Bearer 请求头时才读取网页登录会话（`fscrm_session`）。适用于浏览器同源调用。

两种情况都没有有效身份时返回 `401 {"error":"UNAUTHORIZED"}`。

API Key 在「设置 → API Key」页面创建，明文只显示一次；数据库仅保存 SHA-256 哈希。服务本身不实现限流，**限流由网关负责**，请在上游按调用方配置配额。

## 权限口径

API Key 关联的用户即视为当前用户，复用与网页端一致的 `accessScopeFor` / 仓储层权限收窄：

- 负责人（OWNER）：仅能看到自己负责的客户、线索、商机，以及自己客户下的合同与订单。
- 管理员（ADMIN）：可访问全部业务对象。

字段可见性也沿用网页端的字段权限，不因走 API 而放宽。

## 分页参数

| 参数     | 含义               | 默认 | 约束                          |
| -------- | ------------------ | ---- | ----------------------------- |
| `limit`  | 本次返回的最大条数 | `50` | 上限 `100`；超过按 `100` 处理 |
| `offset` | 跳过的条数         | `0`  | 非负整数                      |

非法值（负数、非整数、无法解析）回落到默认值。响应体中的 `pagination` 说明本次实际口径：

```json
{
  "data": [ ... ],
  "pagination": { "limit": 50, "offset": 0, "count": 12 }
}
```

- `limit`：实际生效的每页上限。
- `offset`：实际生效的跳过条数。
- `count`：本次 `data` 数组的长度（不等于资源总数）。

本版接口不返回资源总数；需要遍历全部数据时请按 `offset` 递增，直到 `count < limit`。

## 错误响应

| 状态码 | body                           | 含义                      |
| ------ | ------------------------------ | ------------------------- |
| 401    | `{"error":"UNAUTHORIZED"}`     | 无有效身份或 API Key 无效 |
| 404    | `{"error":"UNKNOWN_RESOURCE"}` | 资源不在白名单中          |
| 500    | `{"error":"INTERNAL_ERROR"}`   | 服务端读取失败            |

所有响应都带 `Cache-Control: no-store`，避免业务数据被中间层缓存。

## 调用示例

```bash
# 默认分页：最多 50 条
curl -H "Authorization: Bearer fscrm_xxxxxxxx" \
  "https://crm.example.com/api/v1/customers"

# 显式分页：取第 21–30 条
curl -H "Authorization: Bearer fscrm_xxxxxxxx" \
  "https://crm.example.com/api/v1/leads?limit=10&offset=20"

# 浏览器同源调用：使用登录会话 Cookie，不传 Bearer
curl -b "fscrm_session=<会话令牌>" \
  "https://crm.example.com/api/v1/orders"
```
